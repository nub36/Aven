# TTS_RESEARCH — Натуральный женский голос Aven (исследование, этап 1)

> Статус: **исследование + прототип**, не production. Голос **не выбран** — выбор делает владелец на слух.
> ADR не создавался (по инструкции). Системный `speechSynthesis` **не удалён** и остаётся бесплатным fallback.
> Дата: 2026-09-25. Ветка `arena/01a0d94f-aven`.

## 1. Задача и критерии

Сейчас Aven говорит браузерным `speechSynthesis` — на многих устройствах это звучит роботизированно.
Нужен естественный русский женский голос: молодая взрослая женщина, спокойная, дружелюбная, уверенная;
не диктор новостей, не ребёнок, не мультяшный, не робот; правильные ударения, интонация, паузы;
корректное произношение времени, дат, денег, автомобильных данных, чисел, уведомлений.

Ограничения: без AI/LLM, без платных API и подписок, без карт/триалов; неясная лицензия → не использовать;
личные данные не отправлять во внешние TTS; честно показывать Local / Cloud.

Целевая задержка до начала звука: идеал < 1 с, приемлемо 1–2 с, 5–10 с — плохо.

## 2. Методика

- **Одинаковые фразы для всех движков** — `research/tts/phrases.json` (T1–T10 из задачи + короткая
  фраза «Готово.» для замера задержки коротких ответов). Тексты подаются уже в «речевом» виде
  (числа словами), чтобы сравнивать голоса, а не чужие нормализаторы. Aven → «Авен» (см. §9, вопрос 1).
- **Где запускалось.** В песочнице агента скачивание весов с Hugging Face / silero.ai / alphacephei
  заблокировано, поэтому генерация идёт в **GitHub Actions** (`.github/workflows/tts-research.yml`,
  публичный репозиторий → бесплатно): обычный CPU-раннер **AMD EPYC 7763, 4 vCPU, 16 ГБ RAM, без GPU**.
  RHVoice собран из исходников и запущен в песочнице (Intel Xeon 2,6 ГГц, **2 vCPU**, 3,8 ГБ, без GPU).
- **Метрики** (`research/tts/results/*.json`): время синтеза каждой фразы (первый «холодный» вызов
  отдельно), длительность аудио, RTF = синтез / длительность (< 1 — быстрее реального времени),
  время загрузки модели, медианная частота основного тона F0 (грубая проверка «женский голос»).
- **Разборчивость (объективно):** ASR round-trip — образец распознаётся Whisper small (faster-whisper,
  CPU), цифры в распознанном тексте переводятся в слова тем же нормализатором, что в прототипе,
  считается WER относительно исходного текста (`research/tts/asr_eval.py`, `results/asr.json`).
  WER ловит проглоченные/искажённые слова и числа, **но не измеряет естественность** — её оценивает владелец на слух.
- **Честно:** агент не может слушать аудио. Оценки «натуральности» ниже — это репутация модели
  и объективные метрики, а не субъективный вердикт. Решение — только после прослушивания.
- **Прослушивание:** `prototype/voice-lab.html` — все образцы по фразам, слепой режим (A/B/C без названий,
  случайный порядок), оценки ★ (хранятся локально, копируются текстом), для сравнения — текущий системный голос.
  MP3-образцы: `prototype/assets/voice-samples/<engine>/<voice>/tNN.mp3`.
- Повторить: изменить `research/tts/ENGINES` (список движков) и запушить в ветку, или запустить
  workflow «TTS Research» вручную. Локально: `pip install …` + `python research/tts/gen_<engine>.py`.

## 6. Shortlist для прослушивания (3–5), без выбора за владельца

1. **Silero v5 CIS base (MIT)** — единственный найденный вариант «нейросетевой русский голос +
   чистая разрешительная лицензия + мгновенно на дешёвом CPU (≈0,25 с на фразу, 0,07 с на «Готово.»)».
   Риск — акцент дикторов (носители языков СНГ): слушать 20 женских голосов, выбрать 1–3 лучших.
   Поднимается на любом VPS/домашнем ПК без GPU. Нужен PyTorch на сервере.
2. **Supertonic 3 (OpenRAIL-M)** — может работать **прямо в браузере** пользователя (максимальная приватность,
   без сервера). На CPU ≈ 2 с на фразу при 8 шагах (можно уменьшить шаги ценой качества). Риски:
   архивированный репозиторий, мультиязычные (не русские) голоса, use-based ограничения OpenRAIL-M.
3. **Qwen3-TTS (Apache-2.0)** — лучший потенциал «живого» голоса и единственный с Voice Design
   («молодая спокойная дружелюбная женщина») + клонированием, но **на CPU 24 с на фразу — неприемлемо**.
   Имеет смысл только с GPU-сервером (стоимость — решение владельца).
4. **Chatterbox Multilingual (MIT)** — клонирование тембра по референсу (нужна запись диктора с согласием
   или голос с лицензией, допускающей клонирование). Желательно GPU. Результаты — §5.
5. **RHVoice Elena (GPL-3.0) / Dasha (CC BY-SA)** — запасной «лёгкий офлайн» вариант: мгновенно, крошечный,
   но звучит синтетично. Заметно лучше eSpeak, но не решает задачу «естественного» голоса.

Для сравнения качества (не для продукта): Silero v5_5_ru (NC — можно купить коммерческую лицензию),
Piper Irina (лицензия данных неизвестна), Vosk (лицензия весов не опубликована).

## 8. Прототип (реализовано, эксперимент)

- **Нормализация только для речи** — `prototype/js/tts/normalize.js` (`AvenSpeechText.normalize`):
  время (9:30 → «девять часов тридцать минут»), даты (25.09.2026, «до 1 марта»), деньги (3 420 ₽, 251,50 ₽),
  км, км/ч, л, л/100 км, %, °C, десятичные, согласование рода/числа («одна минута», «три дела», «одну минуту»),
  словарь (Aven → Авен, т.е., АЗС…). Экранный текст не меняется. Тесты: `node research/tts/normalize.test.js` (26/26).
  Ограничение: косвенные падежи числительных («к 3 часам») не согласуются.
- **TTSProvider** — `prototype/js/tts/providers.js`: `SystemTTSProvider` (speechSynthesis, с пометкой
  «на устройстве / онлайн» по `localService`) и `NaturalTTSProviderExperimental`
  (self-hosted сервер → готовые образцы для T1–T10 → иначе честный fallback на системный голос с тостом).
- **Не блокирует UI**: состояние «Готовлю речь…» (presence `preparing`) → «Говорю…» → «Готова»;
  остановка: ■ Стоп, повторное нажатие 🔊, клавиша Esc. Замер «времени до начала звука» показывается в настройках.
- **Кэш**: только память вкладки (≤ 30 фраз), без localStorage; фразы с цифрами/e-mail/именем пользователя
  не кэшируются; выключается в настройках.
- **Приватность**: в настройках всегда видно, куда уходит текст: «Локально», «Онлайн-голос браузера»
  (предупреждение), «Self-hosted» (только ваш сервер), «Готовые образцы». Внешние облачные TTS не подключены.
- **Настройки → Голос**: движок (Системный / Натуральный · эксперимент), голос, лицензия голоса,
  адрес self-hosted сервера и его статус, ▶ Прослушать, ■ Стоп, «Как Aven прочитает текст», ссылка на A/B-сравнение.
- **A/B** — `prototype/voice-lab.html`.
- **Self-hosted сервер (исследовательский)** — `research/tts/server.py` (stdlib HTTP): отдаёт прототип и
  `/api/tts/voices`, `/api/tts/synthesize`. Движки подключаются при наличии: RHVoice, Silero CIS, Supertonic, Piper.
  Текст запросов не логируется. Голоса с неясной лицензией скрыты по умолчанию.
  Проверено в песочнице с RHVoice: ~0,22 с от запроса до готового WAV.
- Веса моделей в git **не** добавлялись (только MP3-образцы ≈ 11 МБ и метрики).
- По умолчанию движок = **Системный** — поведение Aven для пользователя не изменилось.

## 9. Открытые вопросы владельцу

1. Произношение имени: **«Авен»** или **«Эйвен»**? (сейчас в словаре — «Авен»; меняется одной строкой).
2. Какие голоса понравились на слух (voice-lab → ★ → «Скопировать оценки»)?
3. Архитектура: сервер без GPU (Silero CIS — дёшево, мгновенно) / синтез в браузере (Supertonic — без сервера) /
   GPU-сервер (Qwen3 / Chatterbox — дороже, потенциально естественнее)?
4. Рассматривать ли покупку коммерческой лицензии Silero (v5_5_ru) или облако (класс E) — только по решению владельца.
5. Нужен ли собственный уникальный тембр Aven (клонирование по записи диктора с письменным согласием)?

## 10. Следующие шаги (после выбора владельца)

1. Выбранный движок → минимальный self-hosted endpoint (по образцу `server.py`), замер задержки на целевом железе.
2. Нормализатор: падежи числительных, адреса, телефоны, госномера; словарь ударений для имён пользователя.
3. Для 3D lip-sync: визимы по фонемам (если движок отдаёт длительности) или по амплитуде аудио.
