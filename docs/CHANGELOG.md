### 2026-09-25 (X) — Расширенный сценарный тест голоса-фаворита vd17-design (исследование, не release)

- **Добавлено (исследование, этап 2):** расширенный прогон `qwen3/vd17-design` (Qwen3-TTS, Apache-2.0) —
  21 реальная реплика Aven: короткие ответы («Готово.», «Слушаю.», «Напоминание создано.»), время и даты,
  деньги, автомобиль (пробег, заправка, аббревиатура ГРМ), вопрос, предупреждение, развёрнутый ответ
  и 4 варианта произношения «Aven / Авен». Метрики скорости и разборчивости — в `docs/TTS_RESEARCH.md` §11.
- **Добавлено (прототип):** страница `prototype/voice-lab-vd17.html` — отдельное прослушивание нового теста
  группами, ★ за каждую фразу, проигрывание группы/всех подряд и кнопка «Системный голос» для сравнения
  с текущим голосом. Ссылка добавлена в `voice-lab.html`.
- **Важно:** голос **не внедрён** как обязательный. `speechSynthesis` остаётся движком по умолчанию
  и рабочим fallback; vd17-design — кандидат/фаворит владельца, а не зависимость Aven.
- **Известное:** произношение «Авен» эталонным не вышло ни в одном из 4 вариантов (ASR слышит «А вен»/«Аван»);
  без нормализации (латиница) модель говорит «Айвен». Решение — после прослушивания владельцем.
  На CPU расширенный набор синтезируется 18,5 с на фразу (медиана) — для диалога нужен GPU (§12).

- **Изменено (planning):** зафиксировано текущее продуктовое направление **WEB-FIRST** (ADR-013, Product Direction — может быть пересмотрено владельцем): первая полноценная реализация Aven — самостоятельный полезный веб-сайт; порядок развития Stage 1–6 (сайт → Command Engine → голос → автоматизации/Canvas → оценка мобильного переноса → Android/iOS и другие клиенты).
