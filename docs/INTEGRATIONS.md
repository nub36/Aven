# INTEGRATIONS — Интеграции и внешние сервисы

> **Статус:** проектная документация концептуального уровня. Конкретные провайдеры и API-партнёры не выбраны.
> **Последнее обновление:** 2026-09-25

---

## 1. Общие принципы

- Каждая интеграция имеет **явные permissions**; доступ — минимально необходимый (least privilege, [ADR-008](DECISIONS.md)).
- Секреты интеграций — **encrypted secrets**; в логи не попадают.
- Интеграции включаются/отключаются на уровне системы (админка) и пользователя.
- Состояние и здоровье интеграций мониторятся; сбои честно отражаются в статусах ([ADR-010](DECISIONS.md)).

| Область | Что известно | Где детализировано |
|---|---|---|
| Голос | STT/TTS провайдеры (в вебе — браузерные API как первый кандидат) | [VOICE.md](VOICE.md), [ADMIN.md](ADMIN.md), раздел Voice |
| Email | SMTP/provider, шаблоны, тестовая отправка | [ADMIN.md](ADMIN.md), раздел Email |
| Push-уведомления | Web Push с ограничениями платформы; честные ожидания | [VOICE.md](VOICE.md), [FUTURE.md](FUTURE.md) |
| Хранилище файлов | S3-compatible abstraction (провайдер не выбран) | [DECISIONS.md](DECISIONS.md), ADR-108 |
| Automation-блоки | HTTP/API, Webhook, внешние интернет-события (будущее) | [AUTOMATION.md](AUTOMATION.md) |
| Инструменты интернета | Отдельный модуль-направление (деталей пока нет) | [FEATURES.md](FEATURES.md), раздел 1 |
| Погода | «при доступности — погода» в утреннем обзоре | [UI_UX.md](UI_UX.md), раздел 3 |
| Device-агенты | Desktop-agent с явными permissions (будущее) | [FUTURE.md](FUTURE.md) |

## 3. Внешние события (будущее)

В будущем события/напоминания могут срабатывать по **внешнему интернет-событию** ([FEATURES.md](FEATURES.md), раздел 3.1). Требования: зарегистрированные источники, валидация, лимиты, деградация при недоступности источника.

## 4. API Aven для внешних систем

Action Core доступен через API как источник команд ([ARCHITECTURE.md](ARCHITECTURE.md), раздел 4). Аутентификация, токены и лимиты API — спроектировать на этапе 1 (открытый вопрос).

## 5. Админ-аспекты

Раздел Integrations админ-панели: API providers, configuration, health, encrypted secrets ([ADMIN.md](ADMIN.md)). Emergency Controls позволяют отключить интеграцию целиком.

## 6. Открытые вопросы

1. Конкретные провайдеры: email, погода, push, STT/TTS, S3-совместимое хранилище.
2. Формат и протокол webhook-входящих (безопасность, подписи, rate limiting).
3. Публичный API Aven: версионирование, токены, области доступа.
4. Интеграции с календарями/мессенджерами — в концепции не упомянуты; решать отдельно, не добавлять без запроса.
