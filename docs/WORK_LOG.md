## 2026-09-25 — Создание документационной основы проекта

- **Дата:** 2026-09-25
- **Задача:** Создать документационную основу проекта Aven и зафиксировать концепцию (этап 0; постановка — «Задача агента сейчас»).

### Что конкретно сделано

- Создана структура `/docs` из 17 документов + переработан корневой `README.md`.
- Спецификация концепции распределена по профильным документам без потери деталей:
  - концепция, принципы, цель, примеры — README, PROJECT_PLAN, ARCHITECTURE;
  - главный интерфейс, утро/вечер, UX-принцип, suggestions, история действий, честность статусов в UI — UI_UX;
  - голос: архитектура, веб-MVP, настройки, ограничения платформ — VOICE;
  - напоминания/события (типы, важность), память Aven, модули, авто, финансы, прочие данные, универсальные сущности — FEATURES, DATA_MODEL;
  - Command Engine: intents/actions, конвейер, естественная речь без AI, пользовательские команды, персональный словарь, режим тестирования, confidence, шаблонные ответы — COMMAND_ENGINE;
  - Automation Canvas, типы блоков, запрет пользовательского JS на сервере, готовые шаблоны — AUTOMATION;
  - offline-first, состояния, синхронизация — OFFLINE_SYNC;
  - безопасность и приватность — SECURITY;
  - полная спецификация админ-панели (все 21 раздел) — ADMIN;
  - будущие приложения (mobile, desktop-agent), AI-слой — FUTURE, ARCHITECTURE;
  - Action Core (источники команд, стандартные действия) — ARCHITECTURE;
  - интеграции (что известно из концепции) — INTEGRATIONS;
  - технологический вектор — PROJECT_PLAN (раздел 7) + DECISIONS (ADR-101…108, статус «Предложено/Открыто»).
- Создан начальный реестр решений DECISIONS.md: 10 принятых решений (зафиксированы концепцией: docs-first, ядро без AI, текстовое представление команд, intent→action, подтверждение опасных действий, запрет произвольного JS, offline-first, privacy/security by design, модульность, честность статусов) и 8 предложенных/открытых (стеки, БД, очередь, кэш, хранилище) — предположения НЕ выданы за утверждённые решения.
- Зафиксированы 18 открытых вопросов в PROJECT_PLAN.md (раздел «Открытые вопросы»), включая явные развилки из концепции (Canvas в MVP или нет; пороги confidence; очередь задач; кэш «если обосновано»).
- Созданы CHANGELOG.md (состояние «Project planning / no production release») и AGENT_GUIDE.md (правила работы агентов).
- Приложение НЕ разрабатывалось, зависимости НЕ устанавливались, production-код НЕ создавался.
