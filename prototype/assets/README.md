# Aven character assets

**Статус: утверждено владельцем (2026-09-25).**

Вымышленные semi-realistic персонажи Aven (premium digital-human стиль, единый художественный
стиль для обоих, цветовая идентичность deep blue / indigo / violet):

- `aven-female.png` — Female «Ава» (512×512)
- `aven-male.png` — Male «Авен» (512×512)

История: прежние flat/cartoon аватары были отклонены владельцем и удалены; новые образы
выбраны из сгенерированных кандидатов и утверждены. Персонаж — опциональный Presentation Layer
(`js/character.js`, [docs/CHARACTER.md](../../docs/CHARACTER.md)); при недоступности ассета
или выключенном персонаже отображается нейтральный логотип «A».
