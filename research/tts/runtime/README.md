# Aven TTS runtime — запуск Natural Voice `vd17-design` (development)

> **Статус: experimental, НЕ production.** Это воспроизводимый способ поднять реальный
> Natural TTS (Qwen3-TTS-12Hz-1.7B-VoiceDesign, голос `qwen3/vd17-design` — фаворит владельца,
> [docs/TTS_RESEARCH.md](../../../docs/TTS_RESEARCH.md) §11) и подключить его к прототипу Aven.
> Веса модели (≈4,5 ГБ) скачиваются с Hugging Face **на ваше хранилище** и в репозиторий
> **не попадают**. Покупать что-либо не нужно.

## Два пути (этап 4, TTS_RESEARCH §18)

| | **Б. Modal (рекомендуемый для GitHub Pages)** | **А. Свой GPU-ПК** |
|---|---|---|
| Что нужно | аккаунт Modal (вход через GitHub, Starter $0/мес, **карта не нужна**) | NVIDIA GPU ≥ 8 ГБ VRAM (комфортно 12) |
| Команда | `bash research/tts/runtime/deploy-modal.sh` | см. «Быстрый старт» ниже |
| Адрес для Aven | постоянный **HTTPS** `https://tts--aven-tts-….modal.run` — работает с GitHub Pages | `http://<IP-ПК>:8080` — только открытие прототипа с этого адреса (HTTPS-страница на HTTP не пойдёт, mixed content) |
| Стоимость | $30 бесплатных кредитов **каждый месяц**; L4 ≈ $0,80/ч **только во время синтеза**, в простое $0 (≈37 ч активного синтеза/мес бесплатно) | бесплатно (своё железо/электричество) |
| Холодный старт | после ~20 мин простоя первый запрос ждёт загрузки модели (десятки секунд; фронтенд честно пишет «просыпается…») | нет — сервер всегда загружен |
| Приватность | текст уходит в ваш контейнер Modal (чужой ЦОД, но ваш инстанс) | всё в вашем контуре |

Оба пути дают **один и тот же** `research/tts/server.py` с тем же API — фронтенду без разницы,
где он запущен. `deploy-modal.sh` делает всё: CLI → вход через GitHub → веса в Volume (CPU-контейнер,
без оплаты GPU) → `modal deploy` → печатает HTTPS URL.

## Что получится

```
Прототип Aven (браузер)
  ── POST /api/tts/synthesize {text, voice: "qwen3/vd17-design"} ──▶  этот сервер
                                                                       └─ Qwen3-TTS 1.7B VoiceDesign (GPU)
  ◀──────── audio/wav ────────
```

Если сервер недоступен/отвечает слишком долго — прототип **честно** переходит на системный
голос браузера и показывает «Natural Voice недоступен… — используется системный голос».

## Требования

| Что | Минимум | Почему |
|---|---|---|
| GPU | NVIDIA с **≥ 8 ГБ VRAM** (комфортно 12 ГБ) | веса 1.7B ≈ 4,5 ГБ + KV-кэш (TTS_RESEARCH §12.3) |
| Python | 3.10–3.12 | пакет `qwen-tts` |
| Диск/сеть | ≈ 5 ГБ, доступ к huggingface.co | веса качаются при первом запуске |
| CPU-режим | **только для проверки**, не для диалога | на CPU измерено 18–70 с на фразу (§12.1) — тогда поднимите таймаут в настройках прототипа до ~120 с |

## Быстрый старт Б — Modal (рекомендуемый для GitHub Pages, этап 4 §18)

Одна команда (клонируйте/скачайте репозиторий и запустите — GPU локально не нужен):

- **Windows (PowerShell):**

  ```powershell
  powershell -ExecutionPolicy Bypass -File research\tts\runtime\deploy-modal.ps1
  ```

- **macOS / Linux (bash):**

  ```bash
  bash research/tts/runtime/deploy-modal.sh
  ```

Для Windows нужен только Python 3.10+ с [python.org](https://www.python.org/downloads/)
(при установке отметить «Add python.exe to PATH»); bash/WSL/Git не требуются.
Оба скрипта делают одно и то же: поставят CLI Modal → `modal setup` (браузер:
**Continue with GitHub** — аккаунт создастся сам, Starter $0/мес, без карты; $30 кредитов
каждый месяц) → скачают веса ≈4,5 ГБ в Volume (CPU-контейнер — за загрузку GPU не
оплачивается) → `modal deploy` (GPU **L4**, тот же `research/tts/server.py` без изменений)
→ напечатают **HTTPS URL** вида `https://tts--aven-tts-….modal.run`.

Дальше в Aven: Настройки → Голос → Движок «Натуральный · эксперимент» → в поле
«TTS-сервер Natural Voice» вставьте URL → **«Проверить backend»** (health + настоящая пробная
фраза vd17-design) → «Проверка произвольной фразой» — любой текст синтезируется по-настоящему.
Endpoint заодно сам раздаёт прототип (`https://…modal.run/` открывается как страница Aven —
запросы к API тогда same-origin, CORS даже не нужен).

- **Расходы честно:** оплата поминутно, только пока контейнер жив (синтез/прогрев + до 20 минут
  «тёплого» ожидания после запроса). Простой = $0. $30/мес кредитов ≈ 37 ч L4.
- **Холодный старт:** после ~20 мин без запросов контейнер выключается; первый запрос ждёт
  загрузки модели (десятки секунд). Фронтенд это понимает: быстрый probe → терпеливый повтор
  со статусом «просыпается: ждём cold start сервера (до ~75 с)…». Вторая и следующие фразы —
  секунды.
- **Безопасность:** endpoint публичный (без аутентификации) — любой, кто знает URL, может
  синтезировать в пределах ваших кредитов. Для личного демо приемлемо; URL не публикуйте.
  Секретов в репозитории/frontend нет и не нужно.
- **Остановить:** `modal app stop aven-tts`. **GPU** по умолчанию L4 (24 ГБ, bf16);
  переопределяется `AVEN_MODAL_GPU=A10G modal deploy …`. T4 не подходит (Turing без bfloat16).

## Быстрый старт А — свой GPU-ПК (тот же ПК, что и браузер, или один LAN)

```bash
# 1. Виртуальное окружение вне репозитория (веса и venv в git не попадают)
python3 -m venv ~/.venvs/aven-tts && source ~/.venvs/aven-tts/bin/activate

# 2. Зависимости. Для GPU сначала поставьте CUDA-сборку torch:
#    https://pytorch.org → например: pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install torch --index-url https://download.pytorch.org/whl/cu124   # или cpu-вариант для проверки
pip install -r research/tts/runtime/requirements.txt

# 3. Запуск сервера (из корня репозитория)
AVEN_TTS_QWEN3=1 python research/tts/server.py --host 0.0.0.0 --port 8080 --warmup
# первый запуск: скачает ≈4,5 ГБ весов, загрузит модель, сделает прогрев.
# Опционально ускорение: pip install flash-attn и добавить AVEN_TTS_QWEN3_FA2=1

# 4. Проверка (в другом терминале)
curl http://127.0.0.1:8080/api/tts/health
# → {"ok": true, "status": "ok", "server": "aven-tts-research", "engines": {
#      "qwen3": {"model": "Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign", "device": "cuda", ...}}, ...}
curl -X POST http://127.0.0.1:8080/api/tts/synthesize \
  -H 'Content-Type: application/json' \
  -d '{"text":"Готово.","voice":"qwen3/vd17-design","rate":1}' -o test.wav
# → test.wav — реальный синтез vd17-design
```

## Подключение прототипа

1. Откройте прототип **по HTTP с того же адреса** (самый простой dev-путь):
   `http://<IP-вашего-ПК>:8080/` — сервер сам отдаёт статический прототип, CORS не нужен.
2. Настройки → Голос → **Движок: «Натуральный · эксперимент»** → **Голос: `vd17-design`**
   (теперь он выбран по умолчанию — решение владельца, §11).
3. Поле «TTS-сервер Natural Voice»: пустое (та же страница) или `http://<IP-вашего-ПК>:8080`;
   для GitHub Pages — HTTPS-адрес из `deploy-modal.sh`.
4. Кнопка **«Проверить backend»** — health (сервер/движок+устройство/голоса/latency) **и**
   настоящий короткий синтез vd17-design (звучит пробная фраза), либо **конкретная** причина:
   HTTP-код / timeout / mixed content / сеть-CORS / «адрес не задан».
5. «Настройки → Голос → Всегда отвечать голосом» — включить, если ответы должны
   озвучиваться автоматически (иначе — кнопка 🔊 на ответе / «Прослушать»).
6. Главная → «Что у меня сегодня?» → ответ уйдёт в Natural TTS → «Говорю · Natural» → «Готова».

## GitHub Pages (https://nub36.github.io/Aven/) — честные ограничения

GitHub Pages — **статический** хостинг и не может запускать модель. Рабочие пути:

- **Modal (выбрано, этап 4 §18):** постоянный HTTPS-endpoint из `deploy-modal.sh` —
  страница на GitHub Pages звонит на него напрямую (origin `https://nub36.github.io`
  уже разрешён в CORS сервера). Это штатный путь для public demo.
- **Локальный режим (свой GPU-ПК):** страница открыта по HTTP с адреса самого сервера
  (`http://<IP-ПК>:8080/`) или с `localhost` — без CORS-проблем. `192.168.x.x` — адрес вашей
  LAN: подходит **только** для теста внутри вашей сети, это НЕ штатный адрес Aven, и из
  интернета он недоступен.
- HTTPS-страница не может обращаться к HTTP-серверу (браузер блокирует как **mixed content** —
  обходить security браузера не будем). Поэтому «свой GPU-ПК + GitHub Pages» без HTTPS-прокси
  не работает — в этом случае выбирайте путь Б (Modal) или reverse-proxy/TLS (Caddy/Nginx +
  домен) — дороже и сложнее, см. §13/§18.

## API contract (совпадает с frontend providers.js, не второй API)

```
GET  /api/tts/health   → {"ok": true, "status": "ok", "server": "aven-tts-research",
                          "version": "0.3.0", "engines": {...}, "voices": [...], "uptime_s": …}
GET  /api/tts/voices   → {"voices": [{"id": "qwen3/vd17-design", "label": …, "license": …}]}
POST /api/tts/synthesize
     {"text": "<речевой текст>", "voice": "qwen3/vd17-design", "rate": 1.0}
     → 200 audio/wav (PCM 24 кГц моно)   | 400 unknown voice | 500 engine error
```

- `text` — уже **нормализованный для речи** текст (нормализация — в браузере,
  `prototype/js/tts/normalize.js`; экранный текст Aven не меняется). Лимит 600 символов.
- Ответ **PCM WAV**: браузер играет `<audio>` без перекодирования; на LAN скорость сети
  не важна. MP3/Opus потребовали бы кодека и ничего не дали бы для диалога (секунды аудио).
- `rate` у VoiceDesign не поддерживается моделью — сервер честно отвечает заголовком
  `X-Rate-Applied: ignored`, а не делает вид, что применил.
- Health не синтезирует ничего — мгновенный ответ, время соединения показывает кнопка «Проверить».
- Streaming сознательно **не** реализован на этом этапе (TTS_RESEARCH §12.5): сначала
  стабильный request → audio → playback; streaming через vLLM-Omni — отдельная оптимизация.

## Приватность

- Текст уходит **только с вашего браузера на ваш сервер** — третьи лица не участвуют.
- Сервер **не логирует и не сохраняет** текст запросов (в лог — длина текста и время синтеза).
- CORS — не `*`: разрешены `https://nub36.github.io` и localhost; остальное — через `AVEN_TTS_ORIGINS`.
- Кэш озвучки в прототипе — только память вкладки, фразы с цифрами/именами не кэшируются.

## Troubleshooting

| Симптом в Настройках → Голос | Причина | Действие |
|---|---|---|
| `НЕ подключён — HTTP 404` | По адресу работает **другой** сервер, не этот (нет `/api/tts/*`) | Проверьте, что запущен именно `research/tts/server.py` / деплой `aven-tts`, и порт |
| `НЕ подключён — адрес TTS-сервера не задан…` | Страница по HTTPS (GitHub Pages), поле сервера пустое — статика синтезировать не может | Указать HTTPS-endpoint (путь Б — Modal) или открыть прототип с адреса сервера |
| `просыпается: ждём cold start…` | Modal-контейнер просыпается после простоя (загрузка модели) | Дождаться (до ~75 с); следующие фразы — секунды. Учащить: чаще пользоваться или `min_containers=1` (платно) |
| `timeout` | Сервер есть, но не отвечает (обе стадии проверки) | Firewall/адрес; запущен ли процесс; жив ли деплой `modal app list` |
| `mixed content` | Страница HTTPS, сервер HTTP | Открыть страницу по HTTP с адреса сервера **или** поднять HTTPS endpoint (путь Б) |
| `сеть/CORS` | Нет соединения или origin не разрешён | Проверить адрес; добавить origin страницы в `AVEN_TTS_ORIGINS` |
| `vd17-design` синтез идёт десятки секунд | Сервер на CPU | GPU обязателен; для CPU-проверки поднимите таймаут (Настройки → Голос → «Таймаут Natural») до ~120 с |
| `engine unavailable: …` в консоли сервера | Не установлен `qwen-tts`/torch, нет места, нет доступа к HF | См. шаги 1–2 быстрого старта; сервер продолжит работу без движка |
