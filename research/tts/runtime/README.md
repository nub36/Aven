# Aven TTS runtime — запуск Natural Voice `vd17-design` локально (development)

> **Статус: experimental, НЕ production.** Это воспроизводимый способ поднять реальный
> Natural TTS (Qwen3-TTS-12Hz-1.7B-VoiceDesign, голос `qwen3/vd17-design` — фаворит владельца,
> [docs/TTS_RESEARCH.md](../../../docs/TTS_RESEARCH.md) §11) на своей машине и подключить его
> к прототипу Aven. Веса модели (≈4,5 ГБ) скачиваются с Hugging Face **на ваш компьютер**
> и в репозиторий **не попадают**. Покупать ничего не нужно: требуется только свой ПК с GPU.

## Что получится

```
Прототип Aven (браузер)
  ── POST /api/tts/synthesize {text, voice: "qwen3/vd17-design"} ──▶  этот сервер (ваш ПК)
                                                                       └─ Qwen3-TTS 1.7B VoiceDesign (GPU)
  ◀──────── audio/wav ────────
```

Если сервер недоступен/отвечает слишком долго — прототип **честно** переходит на системный
голос браузера и показывает «Natural Voice недоступен… — используется системный голос».

## Требования

| Что | Минимум | Почему |
|---|---|---|
| GPU | NVIDIA с **≥ 8 ГБ VRAM** (комфортно 12 ГБ) | веса 1.7B ≈ 4,5 ГБ + KV-кэш (TTS_RESEARCH §12.3) |
| Python | 3.10–3.12 | пакет `qwen-tts` |
| Диск/сеть | ≈ 5 ГБ, доступ к huggingface.co | веса качаются при первом запуске |
| CPU-режим | **только для проверки**, не для диалога | на CPU измерено 18–70 с на фразу (§12.1) — тогда поднимите таймаут в настройках прототипа до ~120 с |

## Быстрый старт (тот же ПК, что и браузер, или один LAN)

```bash
# 1. Виртуальное окружение вне репозитория (веса и venv в git не попадают)
python3 -m venv ~/.venvs/aven-tts && source ~/.venvs/aven-tts/bin/activate

# 2. Зависимости. Для GPU сначала поставьте CUDA-сборку torch:
#    https://pytorch.org → например: pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install torch --index-url https://download.pytorch.org/whl/cu124   # или cpu-вариант для проверки
pip install -r research/tts/runtime/requirements.txt

# 3. Запуск сервера (из корня репозитория)
AVEN_TTS_QWEN3=1 python research/tts/server.py --host 0.0.0.0 --port 8080 --warmup
# первый запуск: скачает ≈4,5 ГБ весов, загрузит модель, сделает прогрев.
# Опционально ускорение: pip install flash-attn и добавить AVEN_TTS_QWEN3_FA2=1

# 4. Проверка (в другом терминале)
curl http://127.0.0.1:8080/api/tts/health
# → {"ok": true, "status": "ok", "server": "aven-tts-research", "engines": {
#      "qwen3": {"model": "Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign", "device": "cuda", ...}}, ...}
curl -X POST http://127.0.0.1:8080/api/tts/synthesize \
  -H 'Content-Type: application/json' \
  -d '{"text":"Готово.","voice":"qwen3/vd17-design","rate":1}' -o test.wav
# → test.wav — реальный синтез vd17-design
```

## Подключение прототипа

1. Откройте прототип **по HTTP с того же адреса** (самый простой dev-путь):
   `http://<IP-вашего-ПК>:8080/` — сервер сам отдаёт статический прототип, CORS не нужен.
2. Настройки → Голос → **Движок: «Натуральный · эксперимент»** → **Голос: `vd17-design`**.
3. Поле «Self-hosted TTS-сервер»: пустое (та же страница) или `http://<IP-вашего-ПК>:8080`.
4. Кнопка **«Проверить»** — покажет `подключён · aven-tts-research … · голосов: 1 · … мс`
   либо **конкретную** причину: HTTP-код / timeout / mixed content / сеть-CORS.
5. «Настройки → Голос → Всегда отвечать голосом» — включить, если ответы должны
   озвучиваться автоматически (иначе — кнопка 🔊 на ответе / «Прослушать»).
6. Главная → «Что у меня сегодня?» → ответ уйдёт в Natural TTS → «Говорю · Natural» → «Готова».

## GitHub Pages (https://nub36.github.io/Aven/) — честные ограничения

GitHub Pages — **статический** хостинг и не может запускать модель. Для public demo есть два честных пути:

- **Локальный режим (сейчас):** страница открыта по HTTP с адреса самого сервера (см. выше) или с
  `localhost`. Работает без CORS-проблем. `192.168.x.x` — адрес вашей LAN: подходит для теста
  **внутри вашей сети**, из интернета недоступен.
- **HTTPS endpoint (для public demo):** страница по HTTPS не может обращаться к HTTP-серверу
  (браузер блокирует как **mixed content** — обходить security браузера не будем).
  Нужен HTTPS перед сервером: reverse-proxy с TLS (Caddy/Nginx + сертификат домена) или
  туннель с публичным HTTPS-адресом. Тогда:
  1. добавьте туннельный origin в CORS сервера:
     `AVEN_TTS_ORIGINS="https://nub36.github.io" AVEN_TTS_QWEN3=1 python research/tts/server.py …`
     (origin `https://nub36.github.io` уже разрешён по умолчанию; добавляйте сюда адрес самого
     туннеля только если открываете страницу через него);
  2. в настройках прототипа укажите **HTTPS**-адрес endpoint.
  Владелец пока не выбирал способ публикации — это отдельное решение (см. TTS_RESEARCH §13).

## API contract (совпадает с frontend providers.js, не второй API)

```
GET  /api/tts/health   → {"ok": true, "status": "ok", "server": "aven-tts-research",
                          "version": "0.3.0", "engines": {...}, "voices": [...], "uptime_s": …}
GET  /api/tts/voices   → {"voices": [{"id": "qwen3/vd17-design", "label": …, "license": …}]}
POST /api/tts/synthesize
     {"text": "<речевой текст>", "voice": "qwen3/vd17-design", "rate": 1.0}
     → 200 audio/wav (PCM 24 кГц моно)   | 400 unknown voice | 500 engine error
```

- `text` — уже **нормализованный для речи** текст (нормализация — в браузере,
  `prototype/js/tts/normalize.js`; экранный текст Aven не меняется). Лимит 600 символов.
- Ответ **PCM WAV**: браузер играет `<audio>` без перекодирования; на LAN скорость сети
  не важна. MP3/Opus потребовали бы кодека и ничего не дали бы для диалога (секунды аудио).
- `rate` у VoiceDesign не поддерживается моделью — сервер честно отвечает заголовком
  `X-Rate-Applied: ignored`, а не делает вид, что применил.
- Health не синтезирует ничего — мгновенный ответ, время соединения показывает кнопка «Проверить».
- Streaming сознательно **не** реализован на этом этапе (TTS_RESEARCH §12.5): сначала
  стабильный request → audio → playback; streaming через vLLM-Omni — отдельная оптимизация.

## Приватность

- Текст уходит **только с вашего браузера на ваш сервер** — третьи лица не участвуют.
- Сервер **не логирует и не сохраняет** текст запросов (в лог — длина текста и время синтеза).
- CORS — не `*`: разрешены `https://nub36.github.io` и localhost; остальное — через `AVEN_TTS_ORIGINS`.
- Кэш озвучки в прототипе — только память вкладки, фразы с цифрами/именами не кэшируются.

## Troubleshooting

| Симптом в Настройках → Голос | Причина | Действие |
|---|---|---|
| `не подключён — HTTP 404` | По адресу работает **другой** сервер, не этот (нет `/api/tts/*`) | Проверьте, что запущен именно `research/tts/server.py`, и порт |
| `timeout` | Сервер есть, но не отвечает за 3 с | Firewall/адрес; запущен ли процесс |
| `mixed content` | Страница HTTPS, сервер HTTP | Открыть страницу по HTTP с адреса сервера **или** поднять HTTPS endpoint |
| `сеть/CORS` | Нет соединения или origin не разрешён | Проверить адрес; добавить origin страницы в `AVEN_TTS_ORIGINS` |
| `vd17-design` синтез идёт десятки секунд | Сервер на CPU | GPU обязателен; для CPU-проверки поднимите таймаут (Настройки → Голос → «Таймаут Natural») до ~120 с |
| `engine unavailable: …` в консоли сервера | Не установлен `qwen-tts`/torch, нет места, нет доступа к HF | См. шаги 1–2 быстрого старта; сервер продолжит работу без движка |
