# 3D-бюст Female Aven — экспериментальная реконструкция (этап 5, обзор)

> Каталог наполняется автоматически workflow'ем `Avatar 3D Research` (бот-коммит после прогона).
> Что это и честные ограничения — docs/AVATAR_3D_RESEARCH.md. Кратко:

- **Вход:** `prototype/assets/character/master/female-aven-reference.jpg` — утверждённое владельцем
  лицо (вид `tripo-input-master.png` после автоматического удаления фона rembg).
- **Метод:** TripoSR (MIT, пиннинг коммита в workflow), single-image-to-3D на CPU-раннере GitHub
  Actions; текстура 2048 запечена из фото (`tripo-texture-master.png`).
- **Это НЕ финальная Female Aven.** Автоматическая реконструкция по одному фото: нет
  rig/blendshapes/отдельных глаз и век; невидимые части (затылок, спина плеч) — правдоподобная
  реконструкция алгоритма, а не утверждённая внешность.

## Решение владельца (A/B, docs/AVATAR_3D_RESEARCH.md §5)

- **A — похоже:** экспериментальный GLB остаётся 3D-этапом, следующий шаг — ручная доработка
  (Blender: риг, blendshapes, ARKit-набор).
- **B — не похоже:** модель НЕ называется Female Aven; варианты — Blender-скульпт по reference,
  дополнительные виды (профиль, 3/4), внешний image-to-3D (платный — только по решению владельца),
  3D-художник.

Сравнение с reference — на странице `prototype/aven-3d.html` (модель можно крутить; reference
показан рядом) или по рендерам этого каталога.
