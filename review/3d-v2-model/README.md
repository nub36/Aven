## Clay geometry review (2026-09-27, вторая итерация)

Визуальная оценка геометрии по превью-листу оказалась невозможной (лицо выглядело
как белая маска) — добавлена **честная clay-диагностика** (геометрия НЕ менялась):

- `clay-full-comparison.jpg` — 7 ракурсов (front / L34 / R34 / L-profile / R-profile /
  back / top), в каждой строке REFERENCE | V2 CLAY.
- `clay-face-closeup.jpg` — лицо крупно, 5 ракурсов, REFERENCE (кроп по 478
  ландмаркам) | V2 CLAY.
- Материалы: нейтральный матовый clay (серо, metallic 0, roughness 0.72); глаза —
  отдельная геометрия, более тёмный нейтральный материал; волосы/одежда/ресницы/
  текстуры/makeup/vertex colors отключены.
- **Гарантия соответствия:** рендеры сделаны НЕ из blend-исходника, а ПРЯМЫМ
  ИМПОРТОМ `prototype/assets/3d/female-aven-v2.glb` (sha256 60734adde326…);
  дополнительно каждая вершина импортированного Body сверена KDTree с базисом
  сборки (max отклонение < 1e-4 м); все 58 морфов = 0 (нейтральное выражение,
  рот закрыт, evaluated == basis).
- Воспроизведение: `research/3d/v2/clay_review.py` (bpy-рендеры + верификация) и
  `research/3d/v2/compose_clay_sheets.py` (листы; только crop/resize/compose).

**Решение владельца по геометрии лица:** A) достаточно похожа → сохраняем face
mesh, дальше materials/skin/eyes/hair; B) частично → правим конкретные области;
C) не похожа → landmarks/TPS fit недостаточен, нужен ручной sculpt/другой face-fit.
