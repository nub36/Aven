## Общая композиция и стиль (одинаково для всех кандидатов)

- **Бюст:** голова + полная шея + немного плеч + верх груди; нижний край кадра немного
  ниже ключиц — кадр «виртуального собеседника при видеозвонке». Не персонаж до пояса, не полное тело.
- **Стиль:** premium realistic / semi-realistic 3D digital human; clean, premium, calm,
  modern, slightly futuristic, НЕ sci-fi. Ориентир качества — современный игровой/virtual
  character; дизайн оригинальный, без копирования конкретных игр и персонажей.
- **Освещение одинаковое:** мягкий key спереди-слева, лёгкий rim, субтильный fill.
- **Фон:** deep navy / indigo gradient — **только для preview**. Будущая 3D-модель не должна
  зависеть от встроенного фона: в WebGL фон управляется интерфейсом Aven отдельно.
- **Ракурс:** фронтальный или небольшой 3/4; взгляд примерно на пользователя; нейтральное
  положение головы; спокойное дружелюбное выражение, рот закрыт.
- **Различаются:** лицо, причёска, небольшие детали одежды.

## Происхождение и лицензия кандидатов

- Все 4 изображения — **оригинальные изображения, сгенерированные в рамках проекта Aven**
  (Arena Agent Mode, генеративная image-модель). Это AI-generated artwork проекта.
- Не являются копией реальных людей, знаменитостей, персонажей игр/фильмов; не содержат
  сторонних ассетов, ripped-моделей и материалов с сайтов «free download».
- Сторонних лицензионных ограничений нет: не использованы материалы с NC/ND/неизвестной
  лицензией. Файлы кандидатов хранятся в репозитории проекта.
- Кандидаты — только референс внешности. Если для настоящей 3D-модели позднее будет
  использоваться сторонняя base-модель, она проходит отдельную лицензионную проверку
  (источник, автор, URL, лицензия, коммерческое использование, модификация, распространение
  с веб-продуктом); лицензия непонятна — кандидат отклоняется. Долгосрочная цель —
  оригинальная Female Aven 3D model, права на которую контролирует проект.

## Чек-лист требований к будущей 3D-модели (после утверждения внешности)

- **Формат:** GLB/GLTF предпочтительно.
- **Геометрия (бюст):** head, neck, shoulders, upper chest.
- **Rig:** head, neck, eyes, jaw (при возможности).
- **Blendshapes/morph targets (минимум):** blinkLeft, blinkRight, jawOpen, smile, frown,
  browUp, browDown, mouthClose + visemes или morphs, из которых они собираются.
- **Visemes речи:** REST, A, E, I, O, U, M/B/P, F/V; при ARKit-подобном или другом стандарте — mapping.
- **Глаза:** отдельные или управляемые rig/morph; естественный взгляд, микродвижения,
  фокус при listening, смена взгляда при thinking, прямой внимательный взгляд при important.
- **Веки:** обязательное моргание, предпочтительно раздельно left/right. Модель без моргания — плохой кандидат.
- **Рот:** закрытое нейтральное положение, jaw open, губные формы, приблизительный viseme
  lip-sync; полностью статичный mesh без управления ртом — отклоняется.
- **Волосы:** качественные hair cards / mesh, стабильный realtime render; без тяжёлой hair simulation.
- **Производительность (web, realtime-friendly):** для каждого кандидата модели указывать
  triangles, texture resolution, material count, approximate GLB size; кинематографические
  модели на миллионы полигонов не рассматриваются. Окончательные лимиты пока не утверждены.
- **Текстуры:** PBR — base color, normal, roughness, при необходимости metallic; подходящая
  skin shading approximation без тяжёлого cinematic renderer.
- **Состояния:** поддержка существующей системы idle / listening / thinking / speaking /
  success / important / waiting / error (event bus, character states, voice integration,
  viseme abstraction, fallback — не переписывать без необходимости).
- **Фон:** модель не зависит от встроенного фона.

## Процесс после этого этапа

1. Владелец смотрит A/B/C/D и говорит «Выбираю вариант X» (либо правки / новые кандидаты).
   **Решение владельца (2026-09-25): лицо зафиксировано по последнему показанному варианту
   (Female D); дальнейший подбор идёт этапами при неизменной идентичности.**
2. **Этап 1 (завершён): причёски** — `stage1-hair/` (HAIR A–D). **Выбор владельца: HAIR A —
   новый MASTER REFERENCE Female Aven** (лицо, форма головы, причёска, длина, пробор,
   выражение, взгляд, шея, плечи, одежда, композиция, фон, свет зафиксированы).
3. **Этап 2 (выполнен, ждёт выбора): цвет волос** — `stage2-color/` (COLOR A–D + сравнительный
   лист `compare-2x2.jpg`); менялся только цвет волос; статус — `stage2-color/README.md`.
4. Этап 3 (после выбора цвета): 4 варианта макияжа.
5. Только после выбора решаем pipeline настоящей модели: custom 3D / character creator /
   commissioned model / licensed base / другой.
6. Невыбранные кандидаты после утверждения могут быть удалены из этой папки.
7. До явного выбора владельца интеграция в основной интерфейс запрещена.
