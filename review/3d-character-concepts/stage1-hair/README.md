## Не менялось между вариантами (проверено визуально)

- лицо и идентичность (image-to-image reference conditioning от `../female-D.jpg`);
- цвет волос: тёмно-каштановый, как у reference;
- макияж: тот же минимальный натуральный;
- одежда: charcoal mock-neck с тонкой асимметричной violet-blue zip-деталью на плече;
- фон: deep navy / indigo gradient (только preview);
- освещение: мягкий key спереди-слева, gentle rim, subtle fill;
- камера/масштаб: бюст — голова, полная шея, ключицы, немного плеч; низ кадра ниже ключиц;
- положение головы: практически фронтальное, как у reference;
- выражение: спокойное дружелюбное, рот закрыт, взгляд на пользователя.

## Варианты причёсок

| Вариант | Файл | Описание | Пригодность для realtime 3D |
|---|---|---|---|
| **HAIR A** | `hair-A.jpg` | распущенные прямые волосы примерно до плеч, естественный объём, аккуратный современный вид | простая silhouette-форма, hair cards/mesh без симуляции |
| **HAIR B** | `hair-B.jpg` | длинные распущенные немного ниже плеч, очень лёгкая естественная волна, без чрезмерного объёма | лёгкая волна задаётся геометрией cards, без dynamics |
| **HAIR C** | `hair-C.jpg` | современное каре / long bob до линии челюсти или немного ниже, не мультяшное | компактный контур, cheapest для realtime |
| **HAIR D** | `hair-D.jpg` | собранные волосы как у reference (низкий мягкий пучок), чуть более современная мягкая укладка, несколько аккуратных естественных прядей | собранный силуэт = минимальная динамика в realtime |

Запрещённые элементы отсутствуют: сложных кос, экстремальной длины, фантастических
причёсок, огромного объёма, аксессуаров нет.

## Процесс

1. Владелец выбирает причёску: «Беру HAIR X».
2. Только после этого — ЭТАП 2: 4 цвета волос (то же лицо + выбранная причёска, меняется
   только цвет): очень тёмный brown/soft black; medium/dark brown; светло-коричневый/dark
   blonde; натуральный auburn. Без синего/фиолетового/розового/кислотных.
3. Затем ЭТАП 3: 4 варианта макияжа (Natural / Soft Professional / Elegant / Aven Signature
   с очень тонким холодным indigo-blue акцентом у глаз). Без heavy makeup, glitter, fantasy.
4. Интеграция в prototype, rigged 3D model, Male и изменения кода Aven — запрещены на всём
   протяжении этапов (см. корневой README review-папки и ADR-015).
